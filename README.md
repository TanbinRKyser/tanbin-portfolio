# Tanbin Kyser — Portfolio

A responsive portfolio for Md. Tanbin Rahid Kyser, presenting applied AI research, computer vision projects, and full-stack software engineering experience.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run build
```

The site is statically exported to `out/` and configured for Netlify through `netlify.toml`.
